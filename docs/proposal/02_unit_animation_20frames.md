# 02. 「1ユニット約20枚」での動き表現設計

## 1. 制約の分析：なぜ通常は60枚以上かかるのか？

古典的な2.5D FPS（例：『DOOM』）では、1体の敵に **50〜80枚以上** のスプライトを使うのが一般的です。
- 8方向（左右反転込みで5方向） × 歩行4コマ = 20枚
- 攻撃（2〜3コマ × 方向） + 被弾 + 死亡（5〜6コマ） = 30枚以上

これを **「1ユニット約20枚」** に圧縮するには、**「プレイヤーと対峙するゲーム性」を逆手に取った配分**と**2Dプログラム演出による補間**が鍵になります。

---

## 2. 1ユニット20枚の具体的バジェット配分案

戦闘ゲームにおいて、敵ユニットがプレイヤーに背中を向けて走る時間よりも、**「こちらを向いて接近・射撃・怯む」時間の方が圧倒的に長く、視認性も高い**ため、正面〜斜め前〜横に枚数を集中させます。

### 基本構成例（合計20枚）

| カテゴリ | 枚数 | 内訳と用途 |
| :--- | :---: | :--- |
| **1. 待機・構え** | **4枚** | 正面(1)、斜め前(1※左右反転で2方向)、横(1※左右反転で2方向)、背面(1)<br>※これだけで**全8方向の待機・向き表現**をカバー |
| **2. 歩行・移動** | **6枚** | 正面(2コマ)、斜め前(2コマ※反転可)、横(2コマ※反転可)<br>※背面移動は「待機背面＋上下揺れ＆左右反転交互切り替え」で代用（0枚追加） |
| **3. 攻撃・射撃** | **4枚** | 予備動作/構え(1)、発砲/振りかぶり(1)、追撃/リコイル(1)、リロード/隙(1)<br>※攻撃時は基本的にプレイヤー側を向いているため正面系に集中 |
| **4. 遮蔽・特殊** | **2枚** | しゃがみ/カバー状態(1)、警戒/索敵ポーズ(1) |
| **5. 被弾・リアクション** | **2枚** | 小怯み/仰け反り(1)、大怯み/膝つき(1) |
| **6. 撃破・ダウン** | **2枚** | 倒れかけ(1)、地面に倒れた状態(1) |
| **合計** | **20枚** | **左右反転（ScaleX = -1）と組み合わせて全8方向・全状態に対応** |

> [!TIP]
> **背面移動の節約術**: 敵が逃走・巡回で背面を見せているときは、1枚の背面絵を「歩行周期に合わせて `ScaleX` を `1` と `-1` で交互反転＋上下バウンス」させるだけで、左右の足を交互に出して歩いているように見えます（初代『ゼルダ』や古典2D RPGの技法）。

## 3. 20枚を「紙芝居」に見せないための2Dプロシージャル演出

コマ数自体が少なくても、プログラム側で以下の**2Dトランスフォーム＆エフェクト**を重ねることで、驚くほど滑らかで重量感のある動きになります。

### ① 歩行ボビングと傾き（歩く重み）
- 2コマの歩行絵を切り替えるだけでなく、`sin(time)` で描画Y座標をわずかに上下させ、ステップに合わせて画像を `±2〜3度` 傾ける。
- 接地時の影（足元に敷く半透明の黒楕円スプライト）を連動して伸縮させると、**空間に接地して歩いている感**が劇的に向上する。

### ② 攻撃時の「タメ」と「踏み込み」
- 予備動作（構え）で `0.2秒` だけ横幅を少し潰し（スクワッシュ）、発砲/攻撃フレームに切り替わる瞬間にスケールを `1.08倍` に一瞬だけ拡大して手前に迫らせる。
- **マズルフラッシュ（銃口閃光）、斬撃軌跡、薬莢、血飛沫**はユニットの20枚に含めず、**共通の汎用2Dエフェクトスプライト**を上に重ねて発光加算（Additive）で描画する。

### ③ 方向転換の擬似補間（スキュー／幅圧縮）
- ユニットの向きが「正面」から「斜め前」へ切り替わる直前に、一瞬だけスプライトの横幅を `0.85倍` に圧縮してから次の角度の絵に切り替えると、回転しているような立体錯覚が起きる。

### ④ 被弾時のヒットストップ＆シェイク
- 弾が当たった瞬間、ユニットを `0.05秒` 停止させ、白フラッシュ（または赤フラッシュ）＋水平方向の微振動＋ノックバック（2D座標を少し後ろへずらす）を入れる。
- 部位判定で「脚」に当たった場合は「膝つき絵」を `0.5秒` 挟むだけで、手応えが大幅に向上する。

## 4. 拡張オプション：さらに表現を増やしたい場合

もし「1ユニット20枚」の定義を「20枚の完成絵」ではなく**「合計20パーツ（差分レイヤー）」**として組める場合、表現力はさらに数倍に跳ね上がります。
- 例：**下半身（立ち・歩き2種・しゃがみ・横向き）× 6枚** ＋ **上半身（構え・撃ち・怯み・リロード）× 6枚** ＋ **頭/表情差分 × 4枚** ＋ **武器差し替え × 4枚**
- これなら同じ20枚のアセットコストで、**「歩きながら撃つ」「しゃがみながらリロードする」「ヘルメットが吹き飛ぶ」**といった複合モーションをすべて表現できます。

まずは「完成絵20枚＋汎用エフェクト」でシンプルに始め、必要に応じて「上下半身分割」へ移行するのが最も堅実です。
