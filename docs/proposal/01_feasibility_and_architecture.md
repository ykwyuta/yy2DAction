# 01. 技術的実現可能性と2D擬似3D（2.5D）アーキテクチャ

## 1. 「3D化せずに2Dのまま」の定義

本提案では、以下を「3D化しない」の条件として定義します。
- **3Dポリゴンメッシュ・3Dモデル・3Dボーンアニメーションを使用しない**。
- **ゲーム空間の座標・移動・衝突判定・視界（射線）はすべて2D平面 `(x, y)` と向き `θ` で計算する**。
- **描画は2D画像（スプライト／テクスチャ）の拡大縮小・クリッピング・平行移動・Zソートのみで行う**。

この枠組みの中で「原則1人称視点で移動しながら戦う」「3Dのような感覚」を実現するための描画方式を比較します。

---

## 2. 描画・空間方式の比較検討

| 方式 | 概要 | 自由移動・旋回 | 遮蔽物・射線 | 手描き感 | 判定 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **A. レイキャスト＋ビルボード（2.5D）** | 2Dマップに光線を飛ばし壁の高さを算出。ユニットや小物は距離に応じて拡縮描画（初期『DOOM』系） | ◎ 360度滑らかに移動・旋回可能 | ◎ 2Dの線分交差で厳密に判定可能 | ○ 壁は縦帯テクスチャ、ユニットは自由な2D絵 | **★第一推奨** |
| **B. 2D線分透視投影＋ビルボード** | 壁を「2Dの線分」として両端点を画面X・高さへ透視変換し、台形（2D描画）＋ビルボードで描く | ◎ 自由移動・斜めの壁も表現可能 | ◎ 自由な角度の遮蔽物を配置可能 | ◎ イラスト調の壁・背景と好相性 | **★推奨（発展形）** |
| **C. グリッド移動＋補間演出** | 1マス移動・90度回転をベースに、移動時だけ拡大・スライド補間する（現代DRPG系） | △ 移動しながらのエイム・回避が難しい | ○ マス単位で明確 | ◎ 1枚絵の背景をそのまま使える | 不採用（アクション性不足） |

### 推奨方式：2.5D 透視投影（方式AまたはB）＋ ビルボードユニット
『戦場のヴァルキュリア』の「遮蔽物に隠れながら進み、角から覗いて撃つ」感覚や、『バイオハザード』の「廊下を歩きながら迫りくる敵に照準を合わせる」感覚は、**連続的な自由移動（前後・ストレイフ）と滑らかな視点旋回**が不可欠です。

方式A（グリッドベースのレイキャスティング）または方式B（2D線分マップの透視投影）であれば、**3Dエンジンを一切使わず、2Dの Canvas / PixiJS / Godot 2D / Pygame 等だけで完全に滑らかな1人称視点**を作ることができます。

## 3. 3Dのような感覚を作る2D描画の仕組み

### 3.1 カメラとユニット（ビルボード）の投影
1. プレイヤー位置 `(px, py)` と視線角度 `θ` を基準に、敵ユニットの位置 `(ex, ey)` をカメラ相対座標 `(dx, dy)`（`dy` が奥行き距離）へ変換する。
2. 画面上の表示X座標は `screenX = centerX + (dx / dy) * focalLength` で求める。
3. ユニットの表示サイズ（スケール）は `scale = baseHeight / dy` で求める。
4. 奥行き `dy` が大きい順にソート（Zソート）し、壁の奥行きバッファ（1次元のZバッファ）と比較して隠面消去を行う。

これにより、**プレイヤーが近づけば敵が画面いっぱいに迫り、離れれば小さくなる**という3D特有の遠近感・恐怖感が生まれます。

### 3.2 「上下の視点」と「高低差」の擬似表現
純粋な2Dレイキャストは基本水平視点ですが、以下の2Dトリックで十分な「上下のエイム感」を出せます。
- **Yシアー（画面上下シフト）**: 上下見回し（ピッチ）に応じて描画の基準水平線（ホライゾン）を上下にずらす。わずかな上下エイム（頭を狙う vs 脚を狙う）であれば破綻なく表現可能。
- **遮蔽物の高さ表現**: ユニットより低い遮蔽物（土嚢、木箱、腰高の壁）は「高さ係数 `0.5`」の壁として描画することで、**上半身だけ見えている敵**や**しゃがんで隠れる動き**を2Dのまま自然に表現できます。

### 3.3 2Dスプライトでの「部位狙い（ヘッドショット等）」
『バイオハザード』や『戦場のヴァルキュリア』で重要な「頭を狙うと大ダメージ／脚を狙うと減速」は、3Dコライダーなしでも簡単に実装できます。
- 各ユニットの2Dスプライトに対し、正規化座標（`0.0〜1.0`）で **「頭」「胴」「脚」の矩形ヒットボックス** を定義する（例：上部20%が頭、中央45%が胴、下部35%が脚）。
- 発射時、画面中央（またはレティクル位置）がユニットの描画矩形内のどの高さ（割合）に当たったかを判定するだけで、3Dと変わらない部位狙いの手触りになります。

### 3.4 手描き背景・遠景との組み合わせ
- 空や遠景の山・建物は、プレイヤーの向き `θ` に応じて横スクロールする **2Dパノラマ背景（視差スクロール）** にする。
- 地面は単色グラデーション、または2Dの走査線変換（いわゆるMode7風のアフィン変換）でタイル模様を描くことで、空間の広がりと移動速度感を強調できます。
